# Neighborhood Veggies

🌾 **Direct Connection Between Farmers and Consumers**

Neighborhood Veggies is a comprehensive platform that connects farmers directly with consumers for fresh, quality vegetables. Powered by Reliance Industries Limited.

## Features

### For Consumers
- 🔍 Browse fresh vegetables from local farmers
- 🛒 Shopping cart and checkout
- 💳 Secure payment integration
- 📦 Real-time order tracking
- ⭐ Rate and review products
- 🏠 Neighborhood-based delivery
- 📱 Mobile and web access

### For Farmers
- 📊 Manage inventory and listings
- 💰 Direct sales to consumers
- 📈 Analytics and sales dashboard
- 🎯 Target local markets
- 📞 Direct customer communication

## Tech Stack

### Web Application
- **Frontend**: React.js
- **State Management**: Redux
- **UI Library**: Tailwind CSS
- **Backend**: Firebase (Firestore, Authentication, Cloud Functions)

### Mobile Application
- **Framework**: React Native
- **Navigation**: React Navigation
- **State Management**: Redux
- **Backend**: Firebase

### Common
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Storage**: Firebase Storage
- **Payment**: Stripe Integration
- **Hosting**: Firebase Hosting

## Getting Started

### Web Setup
```bash
cd web
npm install
npm start
```

### Mobile Setup
```bash
cd mobile
npm install
npx react-native run-android  # For Android
npx react-native run-ios      # For iOS
```

### Firebase Setup
```bash
firebase login
firebase init
firebase deploy
```
